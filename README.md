# Finanças Igreja ⛪💰

Projeto desenvolvido para automatizar, organizar e auxiliar na gestão financeira de igrejas. 

---

## 🛠️ Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:
* [**Python**](https://www.python.org/downloads/) (3.11 ou superior)
* [**Conda**](https://docs.conda.io/en/latest/) (Miniconda ou Anaconda)
* [**Git**](https://desktop.github.com/download/) (para clonar o repositório).

---

## 🚀 Como Executar o Programa

O projeto possui scripts que automatizam a inicialização para que você não precise abrir o terminal toda vez.

### No Windows
1. Baixe ou clone o projeto na sua máquina.
2. Execute o código para baixar dependências: 
```cmd
conda env create -f environment.yml

```
3. Dê um duplo clique no arquivo `Abrir_Windows.bat`.

### No Linux / macOS
1. Abra o terminal na pasta do projeto.
2. Execute o código para baixar dependências e dar permissão de execução para o script: 
```bash
conda env create -f environment.yml
chmod +x Abrir_Linux.sh

```
3. Execute o arquivo `Abrir_Linux.sh`.
